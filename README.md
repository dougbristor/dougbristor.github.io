# dougbristor.github.io

The landing page for the Bristorbrot repositories: **https://dougbristor.github.io/**

It is one static page (`index.html`) with a fixed list of pinned projects. Each tile says plainly whether there is a live demo or only source. Dates are refreshed from the GitHub API at most once an hour per visitor; the list itself changes only when this file does.

- Project home: [bristorbrot.org](https://bristorbrot.org/)
- Screenshots in `thumbs/` are taken from the live demos on a GPU.
- Inspired by the project index at [snicker02.github.io](https://snicker02.github.io/) by Michael A Prostka. The code here is written fresh.
